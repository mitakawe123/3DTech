# Solar System AR

An augmented reality app built with Unity and Vuforia that displays an interactive 3D solar system using image target markers.

## Features
- Recognizes multiple AR markers simultaneously
- Displays 3D planetary models on each marker
- Planets animate and rotate in the AR scene

## Requirements
- Unity 2021.3 or newer
- Vuforia Engine AR package
- Android or iOS device with camera

## Setup
1. Clone the repo: `git clone <your-repo-url>`
2. Open in Unity
3. Add your Vuforia license key in `Window > Vuforia Configuration`
4. Print or display the marker images from the `Assets/Markers/` folder
5. Build and deploy to your device

## How to Use
Point your camera at a marker to see a 3D planet appear.
Multiple markers can be active at the same time.
